# PositionBar Homebrew tap

```sh
brew install --cask positionbar/tap/positionbar
```

[PositionBar](https://positionbar.com/) requires macOS 26 or later. The Universal DMG supports Apple Silicon and Intel.

This repository contains only the Homebrew cask and these installation instructions. The [release workflow](https://github.com/PositionBar/releases) verifies the public, signed and notarized DMG before updating `Casks/positionbar.rb`. The cask uses the same package as the website and Sparkle.

Version metadata and localized changelog belong to the application source repository. Build receipts belong to GitHub Releases; this tap has no release ledger or Apple signing credentials in its execution path.
